# 현재 구현

2026-10-25 기준. 최초 폴더는 문서만 있었고 devkit은 제공되지 않았습니다. 이후 공식 4.1.5A 클라이언트 ZIP을 실제 확보해 구현했습니다. 초기 서버 중심 제안은 현재 사용자 지시로 대체되었습니다.

| 영역 | 현재 상태 |
|---|---|
| 기반 | 원본 ZIP SHA256·CRC 확인, 공식 고정 소스와 367개 project/file ID 일치 |
| 설치 목록 | 351개 원본 모드 + 추가 4개 + 리소스팩 15개 + 셰이더 1개 = 371파일 |
| 한국어 | 원본 한국어 파일 481개 확인, 추가 4개 모드에도 한국어 내장. 새 전체 번역 프로젝트 없음 |
| 새 아이템 | KubeJS 등록 3종 + 실제 리소스팩 텍스처/모델/이름/급식 설명 |
| 전용 화면 | Electron·React·TypeScript. 메인 버튼, 설정, 진행·오류 상태 |
| 설치 코어 | 해시 검증·재시도·완료 기록·설정 보존·관리 파일 복구 |
| 실행 | Java 17 자동 설치 + Prism 11.1.1 공식 원본 + 전용 데이터 폴더 |
| 계정 | Prism의 Microsoft 로그인 흐름 사용. 자체 OAuth 등록 불필요 |
| 지원 대상 | Windows x64 / macOS arm64 |

## 실제 실행 검증과 남은 확인

- Apple Silicon에서 371개 원본/추가 파일 및 overlays 설치와 Java 17 실행을 확인했습니다.
- Electron 실제 창, 설정 저장, Prism 초기 설정 창 열기, 런처 재시작 후 실행 중 Prism 보호를 확인했습니다.
- 자동 테스트는 다운로드 손상·경로 탈출·사용자 설정 보존·복구·리소스·KubeJS·원본 lock을 검사합니다.
- 실제 Microsoft 로그인·Minecraft 월드 진입·섭취/아이템 표시·음성/음악/조명은 플레이어 계정으로 추가 검증이 필요합니다. Windows에서의 실제 실행은 아직 검증하지 않았습니다.
- 개발 빌드는 코드 서명·macOS 공증이 없습니다. 온라인 팩 업데이트 서버도 아직 없으며 새 런처에 포함한 manifest를 기준으로 업데이트합니다.

## 현재 범위에서 제외한 기능

운영진 GUI·OP 전환·관리 인벤토리·보상/퀘스트·NPC·서버 월드 초기화는 구현하지 않습니다. 이용권 사용 효과도 아직 연결하지 않았습니다. 다중 접속에 필요한 서버 측 동일 모드·KubeJS 배치는 운영 준비 시 필요합니다.

현재 구조는 `launcher/`, `client-pack/`, `kubejs-custom/`, `resourcepacks/`, `build-scripts/`, `docs/`입니다. 실행 방법과 실제 제한은 루트 README를 기준으로 확인합니다.
