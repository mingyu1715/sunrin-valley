# 선린밸리 튜토리얼 시작·마을 이동권 구현 계획

> 실행 기준: 2026-10-28 사용자의 마지막 요청. 구현과 로컬 검증·배포물 준비까지 수행하며 GitHub 업로드, 운영 서버 및 실제 클라이언트 변경은 하지 않는다.

**Goal:** 직접 수정한 퀘스트북을 보존하면서 처음 두 퀘스트와 마을 이동권을 구현하고, 퀘스트 진행을 초기화해서 시작할 수 있는 적용물을 준비한다.

**Architecture:** 기존 FTB Quests ID와 KubeJS 등록·서버 이벤트를 활용한다. 퀘스트 초기화는 명시적인 일회성 오프라인 작업으로 분리하며 접속 때마다 초기화하지 않는다.

**Tech Stack:** Minecraft 1.20.1 / Forge 47.4.0 / KubeJS 2001.6.5-build.16 / FTB Quests 2001.4.17.

## 확정 내용

- 기준 데이터는 사용자가 제공한 `local/ftbquests/saved/2026-10-28-01-29-57`의 29개 챕터다. 배치·삭제·다른 보상 변경은 유지한다. 제공 원본은 수정하지 않는다.
- `3862A7D1A471A215`: 제목 `1. 시작하기`, 목표 나무 곡괭이 1개. 설명은 “환영합니다! 마을에 들어가기 전 아주 간단한 테스트를 진행하겠습니다. 곡괭이를 제작해주세요!”, 목표 문구는 “나무 곡괭이를 제작해주세요!”. 보상은 코그 5개·대장장이 작업대 1개·선린 급식 5개만 제공한다.
- `1E5531421815CDB3`: 제목 `도구 업그레이드?` 유지, 목표 돌 곡괭이 1개. 보상은 코그 5개·선린 급식 5개·마을 이동권 1개만 제공한다.
- 도구 설명: “대장장이 작업대에서 [코그 / 나무 곡괭이 / 조약돌]을 순서대로 넣어 돌 곡괭이로 업그레이드 해주세요.” / “더 높은 등급에는 대장장이 주민이 판매하는 형판이 필요합니다. 도구는 모루에서 계속 수리할 수 있고 마법 부여 또한 유지됩니다.”
- 기존 마을 회관 자동 완료 스크립트를 제거한다. 원본 성장·꾸러미 과제는 미완료로 시작한다.
- 초기화 대상은 FTB 퀘스트 진행·수령 기록과 검증된 관련 해금 상태다. 월드·인벤토리·계정·팀 구성·칭호·랜덤박스/접속 보상 기록은 보존한다. 실제 운영 데이터는 지금 변경하지 않는다.

## 구현 순서

- [x] 제공된 챕터를 복사하고 두 퀘스트 및 한국어/영어 설명을 수정한다. 다른 챕터의 의미상 변경이 없는지 비교한다.
- [x] `kubejs:town_warp_ticket`을 추가한다. 구현 기본값은 우클릭 성공 시 1개 소모, 실패 시 보존이다. 개인 침대가 아닌 오버월드 공용 스폰을 매번 읽고 안전한 도착 위치를 검증한다. 기존 아이템은 유지한다.
- [x] 마을 회관 자동 완료를 제거하되 원본 명령어 보상의 개인 대상 지정 수정은 유지한다. 삭제된 지도 퀘스트의 청크 보호 해금은 내집마련 안내 흐름에서 보전한다.
- [x] 초기화 도구를 테스트 사본에서 구현·검증한다. 서버 종료 확인, 정확한 파일 범위, 백업·복원, 재실행 안전성을 제공한다. 자동 완료/단계 연동이 초기화를 되돌리지 않는지 확인한다.
- [x] 다음 모드팩 버전의 클라이언트·서버 배포 파일을 로컬로 빌드한다. 운영 채널 포인터·런처 버전·GitHub 릴리스는 유지한다.
- [x] 단위 테스트 및 실제 Forge 테스트 서버에서 등록·퀘스트 로딩·미완료 시작·스폰 이동·초기화 복원을 검증하고 결과를 남긴다.

## 검증에서 주의할 점

목표 아이템의 내구도·NBT 매칭, 보상 중복, 해금 없는 청크 보호, 스폰 변경/다른 차원/막힌 스폰, 양손 중복 사용, 진행 초기화 후 마을 회관 자동 완료 재발, 초기화 백업 복원을 확인한다. 실제 퀘스트 API·저장 위치를 확인한 후 필요한 파일만 다루며 추측한 월드 파일을 삭제하지 않는다.

## 검증 완료

로컬 후보는 모드팩 0.2.3이다. 전체 회귀 테스트·타입 검사와 실제 Forge 퀘스트/초기화 20개 검증, 최종 이동권 12개 검증을 통과했다. 초기화 뒤 로그인 전 전체 1,131개 퀘스트 진행·수령 기록이 비었고 마을 회관은 미완료로 유지된다. 테스트 서버는 정상 종료했다. 운영 채널·실제 서버·실제 클라이언트·GitHub는 변경하지 않았다.
