# 클라이언트·Prism 연동 런처 구현 계획

현재 사용자 지시(2026-10-25)를 구현하는 실행 계획입니다. 초기 서버 중심 계획을 대체합니다.

**목표:** Windows x64 / macOS Apple Silicon에서 선린밸리 전용 화면으로 원본 4.1.5A·추가 모드·한국어·KubeJS 아이템을 설치하고, Prism 원본으로 Microsoft 로그인 및 게임을 실행합니다.

**구조:** Electron의 메인 프로세스가 파일·다운로드·Prism 프로세스를 관리합니다. React 화면은 제한된 IPC만 사용합니다. Prism은 수정하지 않은 공식 프로그램을 전용 데이터 디렉터리로 실행하며 인증 토큰을 선린밸리가 읽지 않습니다.

## 제약과 검토 초점

- Minecraft 1.20.1, 실제 원본의 Forge 47.4.0, Java 17.
- Sunlit Valley 4.1.5A 원본 ZIP·파일 ID·해시 고정, 추가 모드 4종.
- 새 전체 번역 프로젝트 없음. 원본 한국어 + `lang:ko_kr`, 새 아이템 문구만 추가.
- 건피권·닉변권·선린 급식은 KubeJS 등록, 리소스팩은 외형·언어 담당. 급식은 hunger 8 / saturation 1.0.
- 관리자 GUI·OP·관리 인벤토리·서버 보상·퀘스트·NPC·월드 초기화 제외.
- 다운로드 손상·경로 탈출·재설치 시 사용자 설정 덮어쓰기·사용자 파일 삭제·로그인 필요 상태를 검토한다.

## 후속 변경: Prism 노출 최소화

사용자는 자체 인증으로 전환하지 않고 원본 Prism을 최대한 숨기는 방식을 선택했습니다.

- [x] 일반 실행은 `--launch`만 사용하고 메인 창·정상 로그 콘솔을 띄우지 않는다.
- [x] 이미 설치한 Java와 기본 테마를 지정해 불필요한 최초 설정 페이지를 줄인다. 계정 인증과 필수 오류창은 유지한다.
- [x] 계정 확인·게임 준비·실행 단계를 버튼 아래에 표시한다. Prism 로그에서 고정 단계만 인식하며 원문·인증 정보는 별도 보관/노출하지 않는다.
- [x] 실행 중인 게임은 OS 프로세스로 확인한다. 엔진 출력이 없거나 갱신된 경우 임의 진행률을 만들지 않는다.
- [x] 창을 닫아도 엔진은 유지하고 PID·시작 시각·단계만 저장해 재연결한다. 별도로 연 계정 관리 창은 준비 상태로 묶지 않는다.
- [x] 직접 Prism을 여는 기능은 고급 문제 해결로 옮긴다.
- [x] 기존 계정 파일은 열거나 수정하지 않는다. 실제 사용 중인 기존 Prism 프로세스를 강제 종료하거나 설정을 덮지 않는다.
- [x] 회귀 테스트 49개·실제 로그인 전 화면·macOS 패키지 재연결 검증을 마치고 Windows/macOS 0.1.1 배포물을 생성한다.

추가 변경(사용자 확정): Beat Lamp를 제거하고 StageBox의 Forge 1.20.1 배포본으로 교체한다. 기존 관리 모드 제거·새 모드 설치·설정 보존을 업데이트 경로에서 검증한다.

후속 삭제 기능(현재 구현 범위 제외): Windows는 제거 프로그램으로 앱·전용 데이터 제거를 지원하고, macOS는 앱 삭제와 전용 데이터 정리를 구분하는 방식으로 검토합니다. 현재 데이터를 삭제하거나 이동하지 않습니다.

## 후속 변경: GitHub 원격 모드팩 업데이트

사용자 확정: GitHub의 최신 파일 목록·주소·리소스팩·KubeJS를 읽어 게임 구성을 업데이트한다. 런처 프로그램 변경 때만 새 앱을 배포한다.

구조: 고정 HTTPS `stable.json` → 버전별 manifest/Prism 사양/자체 overlay ZIP의 URL·SHA256. 모드 JAR은 manifest에 기록된 공식 배포처에서 받으며 GitHub에는 자체 파일만 호스팅한다. overlay는 모든 자체 KubeJS 스크립트와 리소스팩을 포함한다. 기존 설치·계정·옵션·월드는 보존하며 실행 중 설치는 차단한다. 최초 원격 기능 지원 런처는 0.1.2다.

- [x] 원격 목록과 세 파일을 검증한 뒤 캐시를 교체한다. 실패/오프라인에서는 마지막 검증본을 사용한다. 최소 런처 버전 미달은 앱 다운로드로 안내한다.
- [x] 설치 코어에 overlay ZIP을 연결한다. 경로 탈출·연결 파일·허용 밖 디렉터리를 거부하고, 제거된 관리 스크립트/팩은 정리한다.
- [x] GitHub 저장소·발행 스크립트를 준비한다. `stable.json`은 버전별 파일 업로드가 끝난 뒤 마지막에 갱신한다. 원본 팩과 다른 저작자의 JAR은 미러링하지 않는다.
- [x] 런처 시작/실행 전 원격 확인, 업데이트 버튼과 다운로드 안내를 연결하고 로컬+실제 GitHub 배포를 검증한다. Windows/macOS 0.1.2를 생성한다.

검토 초점: 부분 다운로드가 검증된 캐시를 덮지 않음; 서버 장애에서 기존 팩 유지; 경로/해시 손상은 설치 전에 차단; 새 릴리스의 관리 파일만 제거; 게임 실행 중 원격 메타데이터 확인이 실제 설치 파일을 변경하지 않음.

추가 확정: Stay True·BSL을 공식 파일로 추가하고 기존 Complementary Reimagined를 유지한다. 실제 설치에서 Sunlit 전용 → 선린 커스텀 → 기존 호환 팩 → Stay True 순서를 확인했으며 셰이더 비활성·개인 옵션·월드를 보존했다. 메모리는 최소 8GB/권장 12GB를 표시하고 시스템 16GB는 8GB, 24GB 이상은 12GB를 추천한다. 자동 테스트 140개 및 실제 GitHub 발행 Action, 익명 다운로드, 오프라인 캐시, macOS 배포 앱 설정 저장 검증을 통과했다.

## 후속 변경: 운영 버전과 예약 업데이트

범위: 기존 UI·GitHub 자동 발행·Prism 흐름을 유지하고 화살표 버그, 운영 채널, 예약 서버 업데이트 준비, 실패 복구, 간단한 변경 내역/점검 표시만 추가한다. 실제 서버는 아직 연결하지 않는다.

- [x] 화살표 hover/click 이동을 Chromium 좌표로 재현하고 아이콘 기준 좌표만 수정한다. 다른 버튼 디자인은 보존한다.
- [x] 발행기는 `published.json`과 버전별 기록만 갱신한다. `operating.json`이 활성 릴리스·점검 상태를 선택하고 기존 `stable.json`은 운영 릴리스 호환 주소로 유지한다.
- [x] 기본 비활성 `server-ops/` 설정과 목표 버전/시각 예약을 준비한다. 공지→저장/동결→백업→종료→업데이트→재시작→상태 검증 후에만 운영 버전을 승격한다. 실패 시 이전 서버 파일/데이터를 복구한다.
- [x] 클라이언트 설치에도 변경 파일 저널을 추가해 실패한 업데이트를 되돌리고 중단 후 복구할 수 있게 한다. 실행 중인 Prism/게임에는 복구를 수행하지 않는다.
- [x] 기존 상태 영역에 점검 상태와 접힌 변경 내역만 표시한다. 단위/모의 서버/실제 Electron 회귀 검증을 통과했다. Windows/macOS 배포 빌드를 준비한다.

운영 전환은 발행과 별도다. 서버 구축 전에는 운영 버전0.1.2와 미구축 상태를 명시하고 실제 서버의 저장/종료/시작 명령은 실행하지 않는다.

검증: 전체185개 테스트, 네 가지 화면 크기에서 화살표 상대 좌표·크기 보존, 전체 실제 모드팩에 늦은 실패를 주입한 뒤 스크립트·옵션·설치 기록의 바이트 단위 복원, 정상 복구의 모드 추가 다운로드0건, Prism11.1.1 기동을 확인했다. 코드 검토에서 발견한 대소문자/유니코드 별칭 저널 중복과 운영 승격 후 복구 상태 선택도 실패 재현 후 수정했다.
