# 선린밸리 Mac 설치 가이드

Apple Silicon(M1·M2·M3·M4 등)용 런처 1.0.0 기준입니다.

## 1. DMG로 설치하기

1. [공식 1.0.0 다운로드 페이지](https://github.com/mingyu1715/sunrin-valley/releases/tag/launcher-1.0.0)의 **Assets**에서 **`Sunrin-Valley-1.0.0-mac-arm64.dmg`**를 받습니다.
2. DMG를 두 번 클릭해 엽니다.
3. 열린 창의 **Sunrin Valley 앱을 오른쪽 Applications(응용 프로그램) 폴더로 드래그**합니다.
4. 복사가 끝나면 Finder에서 선린밸리 디스크를 추출합니다.
5. **응용 프로그램 → Sunrin Valley**를 실행합니다.

기존 앱이 있다면 먼저 종료하고 같은 위치의 새 앱으로 대치합니다. 계정·설정·월드는 별도 데이터 폴더에 유지됩니다.

## 2. 첫 실행 보안 안내

Mac 배포물에는 앱 번들 검증용 **무료 로컬 서명(ad-hoc)**을 적용했습니다. **Apple Developer ID 서명과 공증은 적용하지 않았으므로** 개발자를 확인할 수 없거나 Apple이 악성 소프트웨어 여부를 확인할 수 없다는 경고는 표시될 수 있습니다.

위 공식 GitHub에서 받은 파일인지 확인한 뒤, 그런 경고로 실행이 차단되면 [Apple 공식 안내](https://support.apple.com/ko-kr/102445)에 따라 진행합니다.

1. 응용 프로그램에 복사한 Sunrin Valley를 한 번 실행해 봅니다.
2. **시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
3. 아래로 내려 Sunrin Valley 차단 안내 옆의 **그래도 열기**를 누릅니다.
4. 다시 나타나는 확인창에서 **열기**를 선택합니다.

버튼이 없거나 계속 **손상되었다**는 메시지가 나오면 기존 ZIP에서 꺼낸 앱 대신 새 DMG로 앱을 다시 복사하고, 그래도 같으면 오류 화면을 전달해 주세요. 보안 기능 전체를 끄는 작업은 필요하지 않습니다.

## 3. 게임 설치·로그인

1. 런처에서 **게임 설치**를 누르고 용량 안내의 **설치 진행**을 선택합니다.
2. 준비가 끝나면 **게임 실행**을 누릅니다.
3. 필요할 때 열리는 Prism/Microsoft 창에서 Minecraft Java Edition을 이용할 수 있는 계정으로 로그인합니다.
4. 첫 실행의 추가 다운로드가 끝날 때까지 기다립니다. 한국어 설정·모드·리소스팩·Java 17은 자동으로 준비합니다.

오류가 나면 안내창에서 **오류 정보 복사** 또는 **진단 파일 저장**을 눌러 내용을 전달해 주세요.

## 1.0.0 Mac 배포 수정 내용

기존 ZIP은 압축 파일과 체크섬은 정상이었지만, 앱·보조 프로그램·프레임워크의 번들 서명 검증에서 오류가 확인됐습니다. 새 DMG는 앱 전체를 다시 묶어 로컬 서명하고 엄격한 번들 검증을 통과한 앱을 포함합니다. 이 검증은 Apple의 개발자 인증이나 공증을 의미하지 않습니다.
